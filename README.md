# Baj_Antix — حلول رقمية متكاملة

موقع تعريفي متجاوب لعلامة **Baj_Antix**، يعرض خدمات تصميم المواقع وتطوير الأعمال الرقمية والتسويق الإلكتروني. يدعم الموقع العربية والإنجليزية مع تخطيطي عرض من اليمين إلى اليسار (RTL) ومن اليسار إلى اليمين (LTR).

## المزايا

- تصميم متجاوب لمختلف أحجام الشاشات.
- واجهة ثنائية اللغة (العربية والإنجليزية) مع حفظ اللغة المختارة في المتصفح.
- قائمة تنقل مناسبة للأجهزة المحمولة.
- أقسام للتعريف بالمشروع والخدمات والمزايا وآراء العملاء والتواصل.
- مراعاة أساسيات الوصول، مثل رابط تجاوز إلى المحتوى وتسميات عناصر التحكم.
- مبني بتقنيات الويب الأساسية دون الحاجة إلى إطار عمل أو خطوات بناء.

## التقنيات

- HTML
- CSS
- JavaScript

## تشغيل المشروع

لا يتطلب المشروع تثبيت حزم. افتح `Index.html` مباشرة في المتصفح، أو شغّل خادم ملفات محليًا من مجلد المشروع، مثل:

```bash
python -m http.server 8000
```

ثم افتح [http://localhost:8000/Index.html](http://localhost:8000/Index.html) في المتصفح.

## ملفات المشروع

```text
.
├── Index.html   # بنية الصفحة ومحتواها
├── style.css    # التنسيقات والتصميم المتجاوب
├── script.js    # الترجمة والتفاعلات
└── README.md    # معلومات المشروع
```

## التخصيص

- عدّل محتوى الصفحة في `Index.html`.
- عدّل الألوان والتخطيط في `style.css`.
- حدّث النصوص العربية والإنجليزية في كائن `translations` داخل `script.js`.
- لتغيير عنوان التواصل، عدّل رابط `mailto` في `Index.html`.
